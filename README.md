# Habit Tracker

A modern React habit tracking app with streak counters, daily progress, dark mode, and local storage persistence.

## Features
- Add, edit, delete habits
- Mark habits complete with streak tracking
- Daily completion progress
- Dark/light mode toggle
- Responsive design
- Persistent data (localStorage)

## Tech Stack
- React 18
- Vite (fast dev/build)
- Tailwind CSS (styling)
- Vanilla JS (no external deps)

## Quick Start
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173)

## Build for Production
```bash
npm run build
npm run preview
```

**Note:** Recent fixes applied for habit name display and data validation.
